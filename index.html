Customer Analytics Dashboard

AI-Powered Business Intelligence
Problem A DVD rental business had no centralized way to understand customer behavior or predict churn — all analysis had to be done manually through raw SQL queries, with no visibility into which customers were at risk of leaving.
Solution Built a GenAI-powered BI dashboard using FastAPI and PostgreSQL with 5 analytical modules. Customer Retention Prediction

Django Web App + ETL Pipeline
Problem Customer rental and payment data existed in raw transactional tables but was never transformed into something actionable — the business had no systematic way to identify which customers were likely to stop coming back.
Solution Designed a full ETL pipeline using Django management commands that extracts customer data, transforms it into a structured OLAP table with retention labels, and loads churn risk scores per customer. Trained a Random Forest classifier on 7 behavioral features (total rentals, payment frequency, average payment, recency, store ID, active status, rental-per-month rate) and served predictions via a live web form.
Impact Processed all 599 customers through the ETL pipeline into a clean OLAP table. Classified every customer into 3 churn risk levels (Low, Medium, High) and surfaced retention rates per store — giving the business instant, model-driven insight without needing any ML expertise.

Project · 2026
AIS Course · Live on PythonAnywhere

SAP Express Logistics ERP

Full-Featured Web ERP System
Problem An express logistics company was managing shipments, invoicing, and financial reporting manually with no unified system — creating inconsistencies between what was shipped and what was billed, and making financial reporting a slow, error-prone process.
Solution Architected and deployed a full web ERP using Django across 15+ URL routes with dual role-based access — Operators handle customers and shipments, Management accesses billing and reports. Built an automated cost engine that calculates chargeable weight using max(actual, volumetric ÷ 5000) and applies 11% PPN automatically on every invoice.
Impact Replaced entirely manual operations with an integrated system covering AWB generation, invoicing, and 6 financial report types — Income Statement, Balance Sheet, Cash Flow, AR Aging, Trial Balance, and Journal Entries. Auto-billing eliminates manual calculation errors and the system is live on PythonAnywhere with 2 role accounts.
